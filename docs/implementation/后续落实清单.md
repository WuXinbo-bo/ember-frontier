# 后续逐项落实清单

本清单用于基础版本交接。用户已明确：先基础功能，再逐一完善；正式视觉参考《隔离区》，目标为 2.5D 像素。下列未完成项不能因基础代码或测试存在而标记验收通过。

## 第一组：先补齐可玩操作

- [ ] 建造地图选址、合法/非法预览、触屏确认、施工中断和拆除。
- [ ] 玩家武器选择、装填、装备槽、射程/冷却反馈；完整车载操作。
- [ ] 阅读、制作、研究、供电、取消和背包满的完整 UI 操作回归。
- [ ] NPC 邀请玩家、任务协作、施工接管、组织关系可视化。
- [ ] 骑乘、伙伴转交/接管、群体撤退、高阶控制限制的完整界面。

## 第二组：正式 2.5D 像素表现与资产

- [ ] 以用户确认的《隔离区》具体画面确定镜头、像素密度、角色比例与色板。
- [ ] 使用造化素材库搜索、下载和记录来源；按许可证验证可用范围。
- [ ] 角色/感染体/动物的方向图集与 idle/walk/attack/work/hurt/dead/ride 动画。
- [ ] 地形、建筑施工阶段、载具、道具、植被、天气、UI、音效与 BGM。
- [ ] 将实际 GUID、尺寸、pivot、采样和片段映射接入 VisualTheme，替换调试方块。
- [ ] 手机 safe area、触屏手感、像素清晰度、遮挡/排序、不同屏幕镜头与性能。
- [ ] 正式 Landing、封面和发布资料。当前不发布。

## 第三组：原策划完整系统

- [ ] 三条路线 13 分支的差异化产出与 39 研究节点实际效果。
- [ ] 远距离迁移、升降档、真实攻城、围墙破坏与占据边界变更。
- [ ] 动物/植物/特殊感染体的分支演化、局部压力、能力与成本。
- [ ] 灾害水文、漂流、地形断裂、救援和任务重规划。
- [ ] NPC 自主组织研究、车辆、宠物和生物控制；长期供需与经济平衡。
- [ ] 完整 A01–A92 正式验收与每项可复现输入记录。

## 第四组：存档、联机与规模门槛

- [ ] 浏览器真多标签互斥、配额不足、损坏存档与写入延迟集成测试。
- [ ] 存档版本迁移注册表和实际旧档迁移夹具；当前不兼容时拒绝。
- [ ] 造化服务端跨房间销毁/重启的持久化能力合同、配额、授权与条件写证据。
- [ ] 四个真实客户端同局：同箱竞争、死亡/重连、席位、分散区域、暂停投票。
- [ ] 大规模场景调度优化。当前百日规模 tick 未达到目标 20 Hz，不可通过暗删人口降负载。
- [ ] Android/iOS 实机 CPU、内存、FPS、长时运行、切后台和弱网证据。

每完成一项：更新源代码和测试 → 天工实际输入验证 → 必要的平台验证 → 更新证据矩阵 → 提交。不要以“有定义”“构建成功”代替玩法通过。
