## 30/100 日规模实验

设备：Apple M5 Pro，15 逻辑核心，24 GiB 内存；macOS Darwin 25.5.0 / arm64 / Node 24.22.1。完整测量见 `evidence/benchmark-2026-11-11.json`。

这是**人口账本、合法落位、序列化以及 20 个样本 tick**的实验。它没有逐 tick 模拟完整 100 日生存、生产、AI 和网络，不能称为“百日游戏运行通过”。

- 30 个完整日、零死亡：感染体 310000，NPC 3099。
- 100 个完整日、零死亡：感染体 1010000，NPC 10099；完整 JSON 约 26.15 MB。
- 两个规模均通过深度身份与人口审计。声音接收集合与展开参考集合一致（本次 88 个接收者）。
- 100 日样本：模拟 tick p50 约 76.13 ms、p95 约 417.31 ms，**未达到 50 ms / 20 Hz 目标**；当前不通过百日实时性能 Gate。
- 投影样本 p50 约 29.00 ms，p95 约 37.34 ms。
- 20 个差量样本相对全快照减少约 96.52% JSON 字节；这不是实网带宽或四端延迟结果。
- 测量进程 RSS 最后约 952 MB，不能当作浏览器/手机峰值。
